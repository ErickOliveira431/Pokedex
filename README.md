# Pokédex JS

Uma Pokédex simples e interativa desenvolvida com JavaScript puro, consumindo a [PokéAPI](https://pokeapi.co/) para exibir a imagem, o número e o nome dos Pokémon.

## Funcionalidades
- Busca de Pokémon por **nome** ou **número** (ID).
- Navegação entre Pokémon usando os botões **Prev** e **Next**.
- Exibição do sprite animado na tela.

## Tecnologias
- HTML5
- CSS3
- JavaScript (Fetch API)
